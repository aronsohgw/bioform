# Skill: Biomimicry Reference

Domain knowledge mapping nature patterns to architectural applications. This is the core expertise that makes BioForm outputs architecturally meaningful rather than just decorative geometry.

## When to Use
When generating rationale text, selecting variation types, or mapping CV extraction data to architectural geometry. This is the "why this pattern works for buildings" knowledge.

## Category Mappings

### Cellular (Voronoi, Honeycomb, Foam)

**Nature examples**: Dragonfly wings, soap bubbles, giraffe skin, turtle shell, cork, bone marrow

**Architectural applications**:
| Application | Why it works | Scale |
|-------------|-------------|-------|
| Load-distributing facade panels | Voronoi distributes stress evenly across irregular cell walls | Module → full facade |
| Shading screens | Varying cell sizes create gradient light filtering | Panel |
| Acoustic panels | Irregular cell geometry scatters sound reflections | Interior panel |
| Structural partitions | Honeycomb provides max strength-to-weight ratio | Floor plate division |

**Parametric levers**: Cell count, cell size variation, wall thickness, depth extrusion, regularity (pure hex vs irregular voronoi)

**Real-world precedents**: Beijing Water Cube (ETFE cushion voronoi), Airbus bionic partition

---

### Branching (Fractal, Vascular, Dendritic)

**Nature examples**: Leaf veins, river deltas, lightning, lung bronchi, tree canopies, blood vessels

**Architectural applications**:
| Application | Why it works | Scale |
|-------------|-------------|-------|
| Structural columns/trees | Branching distributes load from point to area efficiently | Building structure |
| Circulation networks | Vascular patterns optimize flow distribution | Floor plan / site |
| Canopy structures | Tree-like branching creates large span with minimal material | Roof / pavilion |
| Facade relief | Dendritic patterns create organic depth variation | Panel |

**Parametric levers**: Branch angle, subdivision levels, taper ratio (parent→child thickness), asymmetry, root point positions

**Real-world precedents**: Stuttgart Airport columns (Frei Otto), Qatar Education City mosque

---

### Shell/Surface (Curvature, Folding, Minimal Surfaces)

**Nature examples**: Nautilus shell, flower petals, eggshell, seed pods, kelp blades, butterfly wings

**Architectural applications**:
| Application | Why it works | Scale |
|-------------|-------------|-------|
| Roof shells | Double curvature provides structural rigidity without internal supports | Building envelope |
| Folded plate facades | Folds add rigidity to thin material, create self-shading | Facade system |
| Minimal surface pavilions | Minimal surfaces minimize material while enclosing volume | Pavilion / canopy |
| Undulating walls | Curvature adds rigidity + visual interest to vertical surfaces | Interior / exterior wall |

**Parametric levers**: Curvature intensity, fold angle, fold frequency, surface thickness, boundary conditions

**Real-world precedents**: Sydney Opera House, Heydar Aliyev Center (Zaha Hadid), Mannheim Multihalle

---

### Lattice/Grid (Woven, Interlocking, Tessellation)

**Nature examples**: Spider webs, fish scales, pinecone arrangement, basket weave grass, honeycomb (regular), crystal lattice

**Architectural applications**:
| Application | Why it works | Scale |
|-------------|-------------|-------|
| Diagrid structures | Triangulated lattice provides lateral + gravity load resistance | Full building structure |
| Woven facades | Interlocking strips create visual depth + shading | Facade screen |
| Tessellated cladding | Repeating tiles with variation create systematic yet organic surfaces | Cladding system |
| Space frames | 3D lattice creates lightweight spanning structures | Roof / floor |

**Parametric levers**: Grid angle, grid spacing, member thickness, weave over/under pattern, tessellation tile shape, distortion field

**Real-world precedents**: Beijing CCTV (OMA diagrid), Al Bahr Towers (responsive facade), Louvre Abu Dhabi dome

---

### Spiral (Fibonacci, Helical, Growth)

**Nature examples**: Sunflower head, nautilus cross-section, pinecone spirals, DNA helix, hurricanes, galaxies

**Architectural applications**:
| Application | Why it works | Scale |
|-------------|-------------|-------|
| Spiral ramps/circulation | Golden angle spacing optimizes movement flow | Multi-floor circulation |
| Facade panel arrangement | Fibonacci spiral creates non-repeating organic distribution | Full facade |
| Tower form | Helical twist improves wind performance + maximizes views | Building massing |
| Sunshade fin layout | Spiral arrangement provides varying shade angles throughout day | Facade element |

**Parametric levers**: Spiral arm count, growth rate (golden ratio, Archimedean, logarithmic), pitch, rotation angle per level, center offset

**Real-world precedents**: Turning Torso (Calatrava), 30 St Mary Axe "Gherkin", Guggenheim Museum ramp

---

### Porous (Perforated, Gradient Density)

**Nature examples**: Bone (trabecular), coral, sea sponge, lotus seed head, diatoms, pumice

**Architectural applications**:
| Application | Why it works | Scale |
|-------------|-------------|-------|
| Perforated facade screens | Gradient porosity controls light/views/privacy per zone | Full facade |
| Structural optimization | Dense where load is high, porous where it's low (like bone) | Structural element |
| Ventilation panels | Pore size/density controls airflow rate | Panel |
| Light diffusion ceiling | Variable hole size creates dappled light effect | Interior ceiling |

**Parametric levers**: Hole shape (circle, polygon, organic), hole size range, density gradient direction, solid-to-void ratio, gradient curve (linear, exponential, radial)

**Real-world precedents**: Jean Nouvel's Institut du Monde Arabe, Morpheus Hotel Macau, ICD/ITKE pavilions

## Variation Strategy

When generating 2-4 variations per image, use this logic:

| Variation | Strategy |
|-----------|----------|
| **A — Facade Panel** | Apply pattern directly as surface treatment / screen. Prioritize visual fidelity to source image. |
| **B — 3D Structure** | Translate pattern into load-bearing or spatial logic. Abstract the structural principle. |
| **C — Mixed** | Combine facade treatment with structural influence. Pattern appears at multiple scales. |
| **D — Experimental** | Push the pattern to an extreme — use growth algorithms, animate the pattern, or cross-pollinate with a secondary category. |

## Scale Presentation

| Scale | What to show |
|-------|-------------|
| **Module** | Single repeating unit, detailed. Show joints, thickness, material logic. ~1-3m |
| **Small** | 3-5 modules assembled. Show how pattern tiles/connects. ~5-15m |
| **Large** | Full facade or building envelope. Show how pattern reads at distance. Site context. |
